## Sobre

Este repositório foi criado para os futuros alunos do **Projeto Soli Deo Gloria** que vão estudar o **Basic Training da Liferay**.

O objetivo é oferecer uma documentação direta e fácil de acompanhar, que sirva de apoio para entender os conceitos do treinamento e realizar as atividades e Pull Requests.

## Como usar

Os guias podem ser lidos de duas formas:

- **Para estudar:** leia os conceitos antes de começar uma atividade.
- **Para acompanhar:** consulte o guia correspondente enquanto desenvolve o Pull Request.

Um bom ponto de partida é o guia de início, que também explica como trabalhar com Pull Requests.

>Aviso: Os códigos deste repositório são exemplos de estudo, criados para orientar os alunos e mostrar como os conceitos teóricos podem ser aplicados na prática. Eles não devem ser seguidos cegamente: a mesma lógica pode ser implementada de várias formas, e os exemplos contêm escolhas que podem ser aprimoradas ou refinadas. Nenhum dos códigos que montei é perfeito; vários aspectos podem ser melhorados. Use-os para compreender os conceitos e orientar sua implementação, jamais como muleta para evitar o esforço de encontrar soluções para os problemas do seu próprio código.

## Organização

Os conceitos estão reunidos em `docs/theory/`, independentemente do item em que são usados. As pastas de cada item contêm os guias de atividade/PR e um `README.md` como índice.

```text
docs/
├── getting-started/   início e Pull Requests
├── theory/            conceitos compartilhados
├── javascript/        PRs de JavaScript
├── rest-builder/      PRs de REST Builder
└── service-builder/   PRs de Service Builder
```
