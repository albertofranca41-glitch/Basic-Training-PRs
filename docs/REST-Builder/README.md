# REST Builder

Nesta pasta estão os materiais dos quatro Pull Requests de REST Builder do Basic Training. Acesse cada guia pelo link correspondente:

## PRs de REST Builder

- [1º PR – Acesso aos endpoints Foo e Goo com o client JAR](./First_PR.md): implementação de um programa Java (`Test.java`) que utiliza o client JAR gerado pelo REST Builder para acessar os endpoints de Foo e Goo.
- [2º PR – CRUD de Knowledge Base e Documents and Media com o client JAR](./Second_PR.md): uso do client JAR Headless Delivery para criar, consultar, atualizar e excluir pastas e artigos de Knowledge Base, além de pastas e documentos do Documents and Media.
- [3º PR – Acesso aos endpoints Foo e Goo por recurso OSGi](./Third_PR.md): implementação de um portlet (`R3B2Portlet.java`) que utiliza recursos OSGi da API para acessar os endpoints de Foo e Goo dentro do Liferay.
- [4º PR – CRUD de Knowledge Base e Documents and Media por recursos OSGi](./Fourth_PR.md): uso dos recursos OSGi Headless Delivery no portlet para executar e verificar operações CRUD em pastas e artigos de Knowledge Base, além de pastas e documentos do Documents and Media.
